# ASD-STF100 — Français Technique Simplifié

Norme ouverte de rédaction technique contrôlée en français pour les procédures,
manuels d'exploitation et consignes de sécurité, accompagnée d'un vérificateur
Python (`stf-check`), d'une chaîne documentaire Diátaxis (FR) et de compétences
d'agents IA.

*Open-source Simplified Technical French (STF) specification, Python linter,
PDF generator, and French Diátaxis Docs-as-Code toolkit.*
