# ASD-STF100 — Documentation technique

Bienvenue sur la documentation officielle de **ASD-STF100** (*Français Technique Simplifié*).
Ce dépôt réunit une spécification ouverte de rédaction technique contrôlée, un linter Python
sans dépendance externe, une boîte à outils **Diátaxis (FR) / Docs-as-Code** et des **Agent Skills**.

> **Avertissement de non-affiliation :** `ASD-STF100` est un projet open-source indépendant.
> Il n'est ni affilié à l'ASD, ni approuvé par l'ASD.
> `ASD-STE100` est une marque déposée de l'ASD (UE n° `017966390`).
